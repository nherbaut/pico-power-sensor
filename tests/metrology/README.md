# Metrology acceptance

Follow the [calibration procedure](../../docs/calibration.md). Static accuracy target is 2% over a declared tested current/voltage/temperature range; it is not guaranteed for this unbuilt design.

Verify offset/gain with reference equipment, shunt heating, header-contact loss and ground-reference errors. Compare integrated energy for a known switched load over windows that include startup and recharge. Test ADC saturation and signed current handling.

Validate nominal 10 kHz acquisition while UART and Wi-Fi are active. Publish achieved rate, dropped conversions, read coherence, voltage/current timing skew and measured bandwidth. Check GPIO timing boundaries against a scope. A GPIO transition generated by Linux is a daemon boundary, not an exact instruction or accelerator event timestamp.
