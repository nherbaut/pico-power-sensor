# Schematics

Editable schematic and PCB files live together in the [interposer project](../pcb/interposer/README.md). Keeping the circuit, BOM and mechanical envelope together avoids confusing the interposer with the measurement board.

Use the generated schematic PDF for review and the KiCad schematic for electrical checks. A drawing or a zero-error ERC result is not evidence that the physical power path is safe.
